# Images du site — En Toute Sérénité 74

Déposez vos photos ici avec **exactement** ces noms de fichiers : le site les
affichera automatiquement (sinon un visuel violet de remplacement reste visible).

| Fichier                | Où il apparaît                                  |
|------------------------|-------------------------------------------------|
| `bord-de-mer.jpg`      | Grand fond bord de mer (section d'accueil/hero) |
| `cabinet-1.jpg`        | Carrousel d'accueil — photo 1                   |
| `cabinet-2.jpg`        | Carrousel d'accueil — photo 2                   |
| `cabinet-3.jpg`        | Carrousel d'accueil — photo 3                   |
| `sylvie.jpg`           | Section « Qui suis-je ? » (portrait)            |

Conseils :
- Format `.jpg` (paysage pour le fond, portrait pour `sylvie.jpg`).
- Idéalement < 500 Ko par image pour un site rapide.
- Vous pouvez réutiliser les photos déjà présentes sur l'ancien site.
